Expected columns

Required: name

Optional: rfid_id, category, serial_code, acquired_date, last_calibrated, notes, deleted_at

First row must be a header row. File must be UTF-8 encoded. A category name that doesn't exist yet will be created automatically. Each asset's barcode_id is auto-generated on import (to match its asset ID) - any barcode_id column in the file is ignored.

Rows with a deleted_at value (e.g. from a re-imported export of the archived view) are added directly as archived; leave it blank to add an active item. Accepts YYYY-MM-DD or YYYY-MM-DD HH:MM:SS.
