Help

Quick answers. For anything else, reach out to an admin directly.

How do I check out an item?

Use the Checkout button in the sidebar, scan or search for the borrower, then add each asset by code or search before confirming with a due date.

How do I return or renew a loan?

Open the Transactions tab, find the loan, and use Return or Renew from its row. Batch return handles multiple items from the same borrower at once.

Why can't I unrestrict a member?

Tool keepers file an unrestriction request instead of acting directly; an admin or in-charge staff member reviews it from the Approvals tab.

I forgot my password.

You can't reset your own password from the login screen — ask an admin to reset it for you from the Staff tab.

Something looks wrong or broken.

Note what you were doing and let an admin know directly — there's no in-app bug report yet.

Is there a list of keyboard shortcuts?

Yes — press ? from anywhere, or use the button below.
